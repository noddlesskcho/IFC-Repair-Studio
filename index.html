IFC+SG Repair Tool

Checks IFC+SG files exported from Autodesk Revit 2025 and 2026 and repairs two known export problems: shapes missing their geometry context (IfcShapeRepresentation.ContextOfItems) and empty 3D shapes with no surfaces (IfcClosedShell). Either problem can make the IFC schema check or model processing fail in the CORENET X Submission Portal. It also finds areas exported without geometry (IfcSpace), explains why, and lists them in an Excel report with Revit IDs so you can fix them in Revit. Only IFC4 files are accepted.

Your IFC file is processed locally.It is not uploaded or stored.

      Missing geometry context (ContextOfItems)

      What is wrongEach shape in an IFC file must say which view it belongs to: the 3D model (Body) or the 2D plan outline (FootPrint). These shapes are missing that link, so the portal's IFC schema check can reject the file.

      What the repair doesIt adds the missing link to the model's only matching context. Nothing is deleted and no shape is changed, so no check in Revit is needed. A row marked "(type)" is a Revit type: the fix applies to every placed instance of that type.

      Areas without geometry (IfcSpace): fix these in Revit

      What is wrongThese IfcSpace objects (Revit rooms, spaces and areas) were exported with no shape at all (Representation = $).

      Why they have no geometryThe Why no geometry column reads the area and height that Revit exported for each space. Has area, but Revit could not build the 3D shape means the room is placed and enclosed, but its boundary could not be turned into a 3D shape, usually because of very short or overlapping boundary lines, thin slivers or narrow gaps. Area is 0 means it is not enclosed or is redundant.

      Why the tool does not change themThe IFC file has no correct outline for these spaces, so there is no shape to add. They stay unchanged in the repaired IFC. This is a report only.

      What you should doDownload the areas report. For each row, find the room or area in Revit with Manage › Select by ID and its Revit Lookup ID, and fix it as the report says. Then export the IFC again.
