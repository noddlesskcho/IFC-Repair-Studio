# IFC Repair Studio v0.4.1 Acceptance Checklist

- [x] Desktop theme control removed.
- [x] Source and output folder controls removed.
- [x] Completion UI uses one Open Report menu.
- [x] Default report bundle contains only PDF and HTML.
- [x] PDF is a concise five-page executive report with no detailed record dump.
- [x] PDF includes cover, KPIs, file information, scope, performance, statistics,
  verification, warnings and submission notes.
- [x] HTML contains complete repair records and works without external dependencies.
- [x] HTML includes search, filtering, sorting, pagination, copy, expand and next actions.
- [x] HTML supports light/dark display and responsive layouts.
- [x] CSV and JSON are exported only when requested from the HTML report.
- [x] Debug logging is disabled by default and can be explicitly enabled.
- [x] PDF pages rendered and visually inspected for clipping and overlap.
- [x] Embedded HTML JavaScript passed a syntax check.
